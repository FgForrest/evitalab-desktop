# Localization (i18n)

evitaLab Desktop uses the [Vue i18n](https://vue-i18n.intlify.dev/) plugin (Composition API
mode, configured in `src/renderer/vue-plugins/i18n.ts`). Currently the only locale is English
(`SupportedLocale.En`); all messages live in a single catalog:

```
src/renderer/i18n/en.json
```

The message schema is typed against `en.json` (`MessageSchema = typeof en`), so key typos in
`t(...)` calls are not caught at compile time — double-check keys exist.

## Rules

- **Every user-facing string** (labels, buttons, tooltips, notifications, validation messages,
  placeholders) must go through i18n. No hardcoded English in templates or services.
- Keys are camelCase and **namespaced by feature** — top-level keys: `app` (name, update info),
  `common` (generic `button.*`, `placeholder.*`, `dialog.confirmDialog.*`), `welcomeScreen`,
  `navigation.panel` (navigation panel incl. connection list and manage/help links),
  `connection` (`editor.*`, `removeDialog.*` incl. their forms, buttons and notifications).
- Reuse `common.*` for generic wording (`common.button.cancel`, `common.button.save`, …) before
  adding new keys.
- Conventional sub-structure inside a feature namespace: `button.*`, `form.*`,
  `notification.*` — follow the structure that already exists in the namespace you are editing.

## Usage

In components:

```ts
import { useI18n } from 'vue-i18n'

const { t } = useI18n()
```

```html
<VBtn>{{ t('common.button.cancel') }}</VBtn>
```

With parameters (named interpolation):

```ts
await toaster.success(t('connection.editor.notification.connectionStored', { name }))
```

For rich messages with markup/slots use the `<I18nT>` component (see
`ConnectionRemoveDialog.vue` for an example with a bold connection name).

Outside components (services), import the global instance:

```ts
import { i18n } from '../vue-plugins/i18n'

const message: string = i18n.global.t('...')
```

(`ServerMetadataProvider` does this for connection-test error messages.)

## Adding a new locale

Add the locale to `SupportedLocale`, provide a full message JSON next to `en.json`, and register
it in the `createI18n` `messages` option in `src/renderer/vue-plugins/i18n.ts`.
